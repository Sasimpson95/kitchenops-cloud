# KitchenOps Preview 6B.6 — Full Design-System Conversion

## Scope

This release applies the Preview 6A design foundation across the complete operational product:

- Products and suppliers
- Recipes
- Purchasing, orders, deliveries and receiving
- Inventory, waste, transfers and storage areas
- Stocktakes
- Prep and production
- Handovers
- Reports
- Users, sites, notifications and settings

## Design rules now applied globally

- One responsive page canvas (`ko-page`)
- Consistent mobile and desktop spacing
- Unified card radii, borders and shadows
- Consistent form focus rings and 44px minimum controls
- Shared motion and press feedback
- Consistent table headings and hover treatment
- Android safe-area spacing
- Reduced-motion support

## Version

- Web: `1.0.0-preview6b.6`
- Android version code: `6`
- Android version name: `1.0.0-preview6b.6`

No database migration is required.
