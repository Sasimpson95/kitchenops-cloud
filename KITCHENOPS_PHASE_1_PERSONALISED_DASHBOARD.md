# KitchenOps Preview 5 — Personalised Dashboard

## New
- Edit Dashboard control in the dashboard header.
- Show or hide role-appropriate dashboard widgets.
- Reorder widgets with mobile-friendly up/down controls.
- Reset to recommended Operations, Manager or Chef defaults.
- Preferences are isolated by active business, role, name and site login.
- Preferences persist across refreshes on the same device.

## Notes
- No database migration is required.
- Dashboard preferences are deliberately stored on the device for Preview 5. This works for shared site logins and avoids creating cloud records for anonymous PIN users. Cloud-synced personal preferences can be added later when individual staff accounts are introduced.
