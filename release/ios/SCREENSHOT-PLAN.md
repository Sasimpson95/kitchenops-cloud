Goal

Show the strongest parts of KitchenOps in a clear sequence so a hospitality operator understands the product within a few seconds.

The screenshots should communicate:

KitchenOps brings kitchen operations into one place.

It handles the daily work that matters: prep, stock, purchasing, waste and handovers.

It works for both single-site and multi-site hospitality businesses.

The product looks polished, practical and ready for real operational use.

1. Apple Screenshot Rules

Apple currently allows:

minimum 1 screenshot

maximum 10 screenshots

.png, .jpg or .jpeg

no alpha channel / transparency

Because KitchenOps supports both iPhone and iPad, provide:

an iPhone screenshot set

an iPad screenshot set

If the interface is effectively the same across smaller device sizes, Apple can scale the highest-resolution screenshots down for other supported sizes.

Recommended capture targets

iPhone

Use a current large iPhone Simulator and capture portrait screenshots.

Preferred App Store target:
6.9-inch iPhone

Accepted portrait dimensions include:

1260 × 2736

1290 × 2796

1320 × 2868

Use the exact native resolution produced by the Simulator/device selected.

iPad

Use a current 13-inch iPad Simulator and capture portrait screenshots.

Accepted portrait dimensions include:

2064 × 2752

2048 × 2732

Use the exact native resolution produced by the Simulator/device selected.

Orientation

Recommended:
Portrait throughout the main screenshot set

Do not mix portrait and landscape casually. If one screen genuinely works better in landscape, treat that as a deliberate separate set rather than changing orientation midway through the sequence.

Recommended marketing treatment

Use the KitchenOps purple/white visual identity consistently.
