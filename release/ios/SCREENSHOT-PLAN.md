## Screenshot Style
- Use real KitchenOps screens
- Use clean demo data
- Avoid empty screens
- Avoid personal/customer information
- Keep the same demo site name across screenshots
- Keep the same device orientation
- Use strong, readable headline text above or around the screenshot
- Do not overcrowd the artwork
