# KitchenOps Preview 8 — Launch Experience

## New
- First-run welcome shown once per device on the public entry/login route.
- Help Centre with concise guides for core operational workflows.
- Feedback screen for bug reports, feature requests and general comments.
- About screen with version, release name, product purpose and Simpson Software branding.
- Release Notes screen covering major recent preview milestones.
- Launch-facing Settings organisation and updated integration wording.
- Improved application metadata.

## Configuration
Set `NEXT_PUBLIC_KITCHENOPS_SUPPORT_EMAIL` in local/Vercel environment variables to enable the **Open email app** feedback action. The feedback can always be copied without this setting.

## Version
- Web: `1.0.0-preview8`
- Release name: `Launch Experience`
