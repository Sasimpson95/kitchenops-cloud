# KitchenOps Preview 8 — Site Selection Fix

## Fixed

- Inventory, Purchasing and Storage Areas now wait for the site list to finish loading before showing a no-sites state.
- Operations users with exactly one site now open that site automatically instead of defaulting to All Sites.
- Purchasing hides the All Sites option when the business only has one site.
- Manager site assignments continue to open their assigned site.

No Supabase migration is required.
